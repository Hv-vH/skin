# 雾粉奶油光 · Rosy Cream

以赵露思写真为素材的浅色暖调皮肤：雾粉奶油光背景、樱粉强调色、侧栏人物竖条、着陆页竖幅主视觉与同脸系图标。

A warm, low-contrast portrait skin built from Zhao Lusi photography: creamy rose light, sakura accent lines, a sidebar portrait and a matching icon family.

DeepSeek Harness Web GUI skin plugin. Presentation only: it overrides theme tokens inside `body[data-dsh-rosy-cream]`, serves its own artwork from `/skin-assets/rosy-cream/<sha256>.<ext>`, and mounts decorative layers it fully removes on dispose. It registers with `@smalltailqwq/dsh-client-ui-skin-deep-whale-manager` through `skin.json` and the v2 customization protocol (artwork toggle, accent color, backdrop dimming, wordmark, discreet-hours schedule).

## Install

```sh
dsh plugin --profile desktop add <path-to-this-directory>
```

Then pick the skin under Settings → Skins (皮肤管理).
