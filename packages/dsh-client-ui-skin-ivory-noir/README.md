# 象牙黑金 · Ivory Noir

以三上悠亚写真为素材的暗调皮肤：象牙表面、酒红强调、黑裙竖幅主视觉、冷调胶片质感与同脸系图标。

A dark, film-toned portrait skin built from Yua Mikami photography: ivory surfaces, wine-red accents, a black-dress hero portrait and a matching icon family.

DeepSeek Harness Web GUI skin plugin. Presentation only: it overrides theme tokens inside `body[data-dsh-ivory-noir]`, serves its own artwork from `/skin-assets/ivory-noir/<sha256>.<ext>`, and mounts decorative layers it fully removes on dispose. It registers with `@smalltailqwq/dsh-client-ui-skin-deep-whale-manager` through `skin.json` and the v2 customization protocol (artwork toggle, accent color, backdrop dimming, wordmark, discreet-hours schedule).

## Install

```sh
dsh plugin --profile desktop add <path-to-this-directory>
```

Then pick the skin under Settings → Skins (皮肤管理).
